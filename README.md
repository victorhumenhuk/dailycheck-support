# DailyCheck support and legal pages

The published support page, privacy notice, terms of use and accessibility
statement for the DailyCheck iOS app.

Served at https://victorhumenhuk.github.io/dailycheck-support/

These files are generated by `Deployment/Website/build.py` in the DailyCheck
repository from the sources in `Deployment/Legal`. Edit the sources there and
rebuild; do not edit the HTML by hand.

The app's source code is not in this repository.
